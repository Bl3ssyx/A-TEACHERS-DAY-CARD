# 💜 Cute Teachers' Day Interactive Flip Card

A delightful 2-slide 3D interactive greeting card application built with HTML5, Tailwind CSS, JavaScript, and Web Audio API.

## 🌟 Features
- **Cute Soft Purple Aesthetics**: Glassmorphism elements & particle animations.
- **3D Flip Card**: Interactive cover and customizable inside note.
- **Photo Upload**: Add your custom teacher photo with live preview.
- **Audio / Music Upload**: Play custom audio notes or background music.
- **ZIP Download**: Download ready-to-use codebase directly.

## 🚀 How to Run
1. Unzip the downloaded file.
2. Open `index.html` in any web browser.
